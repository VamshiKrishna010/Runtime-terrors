# Convex functions

| Module | Public functions |
| --- | --- |
| `reports.ts` | `generateUploadUrl`, `submit` (action: strips photo metadata, then clusters and rescores), `byIncident` (privacy-safe view) |
| `incidents.ts` | `list`, `get`, `vote` (one vote per device token, rescores), `myVotes` |
| `evidence.ts` | `list` (Evidence Center), `review` |
| `analytics.ts` | `summary` |
| `migrations.ts` | internal only: `scrubLegacyPrivacy`, `rescoreAll` |

`lib/` holds pure helpers: the canonical scorer (`scoring.ts`), clustering and
consistency checks (`evidence.ts`), `rescoreIncident` (`rescore.ts`) and the
JPEG/PNG/WebP metadata stripper (`stripMetadata.ts`). They are unit-tested by
`npm test` (`tests/verify-convex-logic.mjs`).

Scores are written only by `rescoreIncident`. Do not add a public mutation that
accepts a score or its inputs.

`_generated/` is normally regenerated by `npx convex dev`; run it after adding
a module.
